Measure these before printing

  • Built from your measurements: both boards, cell height, ports, mounting holes, button and LEDs
  • Assumed: M3 mounting holes and the button's height (the tab is 7 mm tall, so close is fine)
  • Set the battery board's slide switch to always-on before closing the case

Printing

  • PLA or PETG, 0.2 mm layers, 3 walls, 15% infill
  • Base upright, lid upside down, no supports
  • Lid snaps on with 0.3 mm clearance. If it's loose, set fit = 0.2
  • ON/OFF is a flex tab in the side wall with a raised dot. The 5 battery LEDs show through slits beside it, and the ESP32's LEDs through a light pipe in the lid.
  • Stack prints as 3 parts: base, tray and lid
  • Files: hardware/enclosure in the repo (.scad + STLs)
